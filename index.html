Kerap Ditanyakan

Apakah MoneTrac+ gratis digunakan?
Ya, MoneTrac+ dapat digunakan 100% gratis tanpa biaya langganan apa pun. Anda bisa langsung mendaftar dan mulai mencatat keuangan serta membuat target tabungan impian Anda.
Bagaimana keamanan data saya?
MoneTrac+ menggunakan arsitektur Supabase PostgreSQL dengan Row Level Security (RLS). Artinya, data transaksi, saldo akun, dan target tabungan Anda dienkripsi dan hanya dapat diakses oleh akun Anda sendiri.
Apakah bisa diakses lewat smartphone / HP?
Tentu saja! MoneTrac+ dirancang 100% responsif dengan Mobile Bottom Navigation Bar khusus sehingga Anda bisa mencatat transaksi pengeluaran secara cepat di mana saja menggunakan smartphone.
Bagaimana cara memindahkan data dari aplikasi / spreadsheet lama?
Pada menu Pengaturan (Settings), tersedia fitur Alat Migrasi 1-Klik di mana Anda cukup menempelkan teks JSON data lama Anda untuk langsung diimpor ke database akun MoneTrac+ Anda.

Siap Mengatur Keuangan Lebih Baik Hari Ini?

Bergabunglah sekarang, catat keuangan Anda dengan mudah, dan wujudkan setiap target impian Anda.
